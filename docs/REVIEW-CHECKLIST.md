# LARIMÍA Frontend Review Checklist

Review each portal for:

- route and loading behavior
- 401 / 403 / 404 / 409 / 422 / 429 / 5xx handling
- retry and timeout behavior
- double-submit protection
- WebSocket reconnect behavior
- responsive layout
- keyboard navigation
- screen-reader semantics
- Spanish/English completeness
- authorization-aware navigation
- PII exposure
- payment-tokenization boundaries
- mobile native permission flows

## Portal ownership

Customer:
- discovery, booking, checkout, live service, membership, safety

Provider:
- onboarding, availability, offers, visit execution, earnings, safety

Operations:
- dispatch, providers, support, safety, finance, catalog, partners, audit
